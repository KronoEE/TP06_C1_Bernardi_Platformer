# TP06_C1_Bernardi_Platformer

Plat-Former es un juego de plataformas 2D creado en **Unity**, donde controlás a un monstruo en un mundo lleno de peligros, enemigos y recompensas.  
Tu objetivo es recolectar monedas, derrotar enemigos y llegar al **portal final** para ganar la partida.

Saltá, esquivá trampas y usá tus ataques para abrirte camino.

## 🕹️ Controles

| Acción | Tecla / Botón |
|--------|----------------|
| Mover a la izquierda | `A` |
| Mover a la derecha | `D` |
| Saltar | `Espacio` |
| Atacar / Disparar | `E` |

---

## ⚔️ Mecánicas Principales

- 💀 **Enemigos:** cada enemigo puede atacarte y causar daño; derrotalos para avanzar.
- 💰 **Monedas:** recolectá monedas a lo largo del nivel.
- 🌊 **Agua:** caer al agua provoca la muerte instantánea.
- 🌀 **Portal Final:** llegá al portal para completar el nivel y ganar.
- ❤️ **Barra de Vida:** mantené tu salud; si llega a cero, el jugador muere.
